# God Tribal — commander build-off

**This folder is a comparison workbench, not a finished deck.** Five variants share one shell and
differ only in commander + God selection + a small commander package, so the commander is the
variable under test:

| File | Commander | Colours |
|---|---|---|
| `DECK-SISAY.md` | Sisay, Weatherlight Captain | WUBRG |
| `DECK-JODAH.md` | Jodah, the Unifier | WUBRG |
| `DECK-ESIKA.md` | Esika, God of the Tree // The Prismatic Bridge | WUBRG |
| `DECK-MOROPHON.md` | Morophon, the Boundless | WUBRG |
| `DECK-KRATOS-ATREUS.md` | Kratos, Stoic Father + Atreus, Impulsive Son | URW |

**There is deliberately no `DECK.md` / `STATUS.md` pair yet.** The repo convention makes that pair
the single authoritative list; until one variant is chosen there is no authoritative list. When a
winner is picked, copy it to `DECK.md`, write `STATUS.md` from it, and delete or archive the rest.

- `research/comparison.md` — the analysis: measured curves, mana, God counts, and a verdict per deck.
- `research/parts/` — the part files the five lists are **assembled from**. Edit those, then run
  `bash research/parts/build.sh` from this folder; never hand-edit a `DECK-*.md`.
- `MOXFIELD-*.txt` — generated by `bun run deck:moxfield god-tribal`; one per variant.
- `research/gods-table.tsv` / `research/all-gods.txt` — every commander-legal God (95), cached.
